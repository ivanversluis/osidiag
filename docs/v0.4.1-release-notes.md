# osidiag v0.4.1

**Windows AMD64 preview: unsigned.** Authenticode signing is **not active**. Windows SmartScreen or Smart App Control may warn or block execution.

## Network troubleshooting

osidiag is a portable, Apache-2.0-licensed Go command-line tool for network troubleshooting across the seven OSI layers on native Windows 11 and Linux (including WSL2). It reads local network interface/link and Wi-Fi state, ARP/neighbor caches, routes and local TCP connections. Explicitly requested checks provide ICMP ping, traceroute, target-specific TCP connectivity, TLS certificate validation and SNI comparison, DNS resolution and HTTP status/redirect observations. It is designed for focused connectivity investigation, not vulnerability enumeration or exploitation.

## Downloads and verification

- **Windows AMD64:** `osidiag-windows-amd64-unsigned.zip` (portable `osidiag.exe`, **not Authenticode-signed**).
- **Linux AMD64:** `osidiag-linux-amd64.tar.gz`.
- **Linux ARM64:** `osidiag-linux-arm64.tar.gz`.
- `SHA256SUMS` contains archive digests. Verify checksums and GitHub build provenance before running. Neither provides a trusted Windows publisher signature.
